Deploy This Single-File Web App on GitHub Pages

Because this entire file transfer app is packed into a single index.html file using WebRTC (PeerJS), it runs 100% free on GitHub Pages with zero backend configuration.

Step 1

Save as index.html

Download this file as index.html and upload it to the root of a public GitHub repository.

Step 2

Enable GitHub Pages

Open Settings → Pages in your repository, set Source to Deploy from a branch, and select main / (root).

Step 3

Pair & Transfer Anywhere

Open your https://<user>.github.io/<repo>/ URL on any two devices, scan the QR code, and drop files.
